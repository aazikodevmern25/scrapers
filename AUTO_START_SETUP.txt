To make everything start automatically when server reboots:

Step 1: Edit crontab
────────────────────────────────────────────────────────────────────────────
Run this command:

  crontab -e

Step 2: Add this line at the bottom
────────────────────────────────────────────────────────────────────────────
Paste this:

  @reboot /home/aaziko/scrapers/auto_start_on_reboot.sh

Step 3: Save and exit
────────────────────────────────────────────────────────────────────────────
  • Press Ctrl+O to save
  • Press Enter
  • Press Ctrl+X to exit

Step 4: Done! ✅
────────────────────────────────────────────────────────────────────────────
Now when server reboots:
  ✅ FastAPI starts automatically
  ✅ Ngrok starts automatically
  ✅ All workers start automatically
  ✅ Queue processing resumes automatically
