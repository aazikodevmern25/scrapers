Problem: "Connection refused"
→ Check FastAPI is running: ps aux | grep uvicorn
→ Check Nginx is running: sudo systemctl status nginx

Problem: "DNS not resolving"
→ Wait longer (up to 1 hour)
→ Check DNS: nslookup scraper.yourdomain.com

Problem: "SSL certificate failed"
→ Make sure DNS is working first
→ Run manually: sudo certbot --nginx -d scraper.yourdomain.com

Problem: "502 Bad Gateway"
→ FastAPI not running or wrong port
→ Check: curl http://localhost:8888/api/v1/health
