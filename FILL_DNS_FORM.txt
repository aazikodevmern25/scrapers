STEP 1: Upgrade Ngrok
→ Go to: https://dashboard.ngrok.com/billing/subscription
→ Choose "Personal" or "Pro" plan ($8-10/month)

STEP 2: Add Your Domain in Ngrok
→ Go to: https://dashboard.ngrok.com/cloud-edge/domains
→ Click "New Domain"
→ Select "Use your own domain"
→ Enter: scraper.yourdomain.com
→ Ngrok will show you a CNAME target like:
   abc123.ngrok-agent.com

STEP 3: Fill Your DNS Form (from screenshot)

┌─────────────────────────────────────────────────────────────┐
│ Type *                                                      │
│ ┌─────────────────────┐                                    │
│ │ CNAME              ▼│  ← Select "CNAME"                  │

└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Name *                                                      │
│ ┌─────────────────────────────────────────────────────────┐│
│ │ scraper                                                 ││ ← Type "scraper"
│ └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ Value *                                                     │
│ ┌─────────────────────────────────────────────────────────┐│
│ │ abc123.ngrok-agent.com                                  ││ ← Paste from ngrok
│ └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ TTL                                                         │
│ ┌─────────────────────┐                                    │
│ │ 1 Hour             ▼│  ← Select "1 Hour"                 │
│ └─────────────────────┘                                    │
└─────────────────────────────────────────────────────────────┘

Then click: "Add More Records" → "Save"

STEP 4: Start Ngrok with Your Domain
→ On your server, run:
   pkill ngrok
   ngrok http --domain=scraper.yourdomain.com 8888

RESULT: https://scraper.yourdomain.com ✅ PERMANENT!
