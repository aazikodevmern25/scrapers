====================================================================
OPTION 1: START ALL SCRAPERS NOW
====================================================================

Run this command:
  bash /home/aaziko/scrapers/start_all_scrapers.sh

This will:
  • Start FastAPI on port 8001
  • Generate new ngrok URL
  • Start all workers (Eximpedia, TradeMap, MacMap)
  • Save URLs to CURRENT_NGROK_URL.txt

====================================================================
OPTION 2: RESTART WHEN NGROK URL EXPIRES
====================================================================

When your ngrok URL expires (server restart), run:
  bash /home/aaziko/scrapers/restart_all_services.sh

This will:
  • Kill old FastAPI and ngrok
  • Start new instances with fresh ngrok URL
  • Keep workers running (no downtime)
  • Update all URL files with new ngrok URL

====================================================================
OPTION 3: AUTO-START ON SERVER REBOOT
====================================================================

Setup once (add to crontab):
  crontab -e

Add this line:
  @reboot /home/aaziko/scrapers/auto_start_on_reboot.sh

Save and exit. Now everything auto-starts on reboot with new URL!

TROUBLESHOOTING
